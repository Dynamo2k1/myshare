Self-hosted text, screenshot and large-file transfer over localhost or your LAN. Resumable multi-GB uploads, live sync, and a real folder browser — in ~16 MB with nothing else to install.

What it does

Everything you actually use a transfer tool for, and nothing you don't.

⬆️

Resumable uploads

A 12 GB file that drops at 7 GB resumes from ~7 GB — never restarts, never held in RAM. Measured: <1 MiB heap for a 3 GiB upload.

📋

Shared clipboard

Paste text on the laptop, tap Copy on the phone. Works over plain-HTTP LAN, with URL / code / markdown detection.

🖼️

Screenshot capture

Ctrl+V anywhere grabs the clipboard image and pushes it live to every open tab.

📁

Folder mode

myshare ~/dir browses a real folder — subdirectories, upload into it, delete real files, live re-scan of outside changes.

▾

Markdown scratchpad

Paste raw markdown, see it rendered live, fullscreen reading mode. Auto-saves and syncs to every device — no button.

🔗

Share links + QR

CSPRNG tokens (only the hash is stored), expiry, download caps, one-time links, QR codes for LAN handoff.

↕️

Live transfer manager

Progress, speed, ETA; pause / resume / cancel / retry; survives a browser refresh.

⚙️

Run as a service

Per-user systemd unit / launchd agent / Scheduled Task — myshare service install, no admin.

Local, LAN, or public — you choose

MyShare filters connections by client IP before auth or routing. Default: local for a loopback bind, lan for --host 0.0.0.0.

ModeWho can reach itUse when
localOnly this machine (127.0.0.1 / ::1).Single machine, or an SSH tunnel.
lanLoopback + private ranges only. Anything else gets 403.Your Wi-Fi. Your phone works; the internet can't — even with the port forwarded.
publicAnyone, including the internet.Only behind a VPN / reverse proxy, always with --auth.

Workflows

# Just this laptop
myshare

# Laptop + phone on the same Wi-Fi (LAN-only, the safe default)
myshare --host 0.0.0.0

# Serve a real folder, keep no state afterwards
myshare ~/Downloads --ephemeral

# LAN-only + a password
myshare set-password
myshare --host 0.0.0.0 --auth
Going public? Don't expose the port directly — put MyShare behind Tailscale, WireGuard, or an authenticating reverse proxy. --access public logs a loud warning at startup for a reason.

Install

Linux, macOS, Windows — amd64 & arm64. Into ~/.local/bin, no root.

git clone https://github.com/dynamo2k1/myshare && cd myshare
make build        # builds the UI (if npm is present) and ./bin/myshare
make install      # copies only ./bin/myshare into ~/.local/bin

myshare --help
myshare --port 8787 --data-dir ~/MyShare

Windows: powershell -ExecutionPolicy Bypass -File scripts\install.ps1 · Prebuilt binaries on the Releases page · Full docs in the README.

Why it's safe to run

Content is stored by SHA-256 and addressed by opaque ID — path traversal is impossible by construction.

Uploaded HTML/SVG is served attachment + nosniff; strict CSP, same-origin only.

Optional argon2id auth with per-IP login rate limiting.

The --access IP filter runs on the real TCP peer, before auth.
